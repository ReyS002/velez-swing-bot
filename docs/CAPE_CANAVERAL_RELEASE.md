# Cape Canaveral desk release — 1.13.0

Cape Canaveral is the sixth room, with Coastal Day and Launch Twilight lighting. The twilight interior uses the approved original art; only the distant pad is cleaned for moving rocket, exhaust and smoke. Daytime retains the same furniture positions.

Tools → Cape Canaveral launches offers a remembered, off-by-default switch and a one-time Preview launch button. Automatic launches wait a random 10–15 minutes of visible Cape room time. A sequence has three seconds of ignition, accelerating ascent, then dispersing smoke; it ends at 64 seconds. Hidden tabs, reduced motion, disabled object motion and expanded chart views pause activity. Changing room cancels a launch. This is an ambient visual effect, not a real launch schedule. No sound or external mission service is used.

The coastal handset is fitted individually to existing desks. Cape retains its photographed phone with a functional Winston screen. Existing rooms gain restrained apron shading to distinguish the desk edge, without changing furniture or flooring. New York's live shelf correction and current panel fixes are retained.

Validation: six rooms × two lighting modes × three editions; seven object navigation paths in each room; launch preferences, duplicate-launch prevention, reduced motion, cancellation, desktop/mobile positioning; node scripts/check_cape_launch.mjs; existing phone, room-module identity and desk-intelligence tests.
