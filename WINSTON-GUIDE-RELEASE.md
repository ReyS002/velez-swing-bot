# Winston room guide — 1.10.0

Optional Tools toggle, off on every reload. Object hover and keyboard focus show captions after a short delay and play reusable Winston clips. Active music, broadcasts, or Winston calls suppress guide narration. Leaving, clicking, changing rooms, hiding the tab, or turning the guide off stops narration. Includes 17 static explanations; no microphone permission or hover-time voice API calls.

Validated in all five rooms across all three dashboards: default-off, keyboard focus, rapid hover changes, media guard, stop and reload behavior.
